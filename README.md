# Whisky Fest Amsterdam 🥃

Officiële webapplicatie voor **Whisky Fest Amsterdam** (Est. 2004) — De Kromhouthal Amsterdam.

## 🚀 Snelle Start

```bash
# Dependencies installeren
npm install

# Lokale development server starten
npm run dev

# Productie build compileren
npm run build
```

## 📍 Festival Informatie
- **Locatie**: De Kromhouthal Amsterdam, Gedempt Hamerkanaal 231, 1021 KP Amsterdam
- **Contact**: `info@amsterdamwhiskyfestival.nl`
- **Sessies**: Vrijdag, Zaterdag & Zondag edities, inclusief de Amsterdamse Whiskytram & Masterclasses.
